## 当前项目现状

### 产品与数据状态

系统是一套使用 FastAPI Mock Engine 的可交互调研平台。研究者通过五个预置应用用户之一登录，创建自己的项目和问卷，自动保存草稿，固化不可变问卷/完整配置版本，受控运行研究轮次，查看明确口径的分析和异常证据，并生成有记录的范围化导出。

生产部署模型由 Next.js frontend、FastAPI backend 和 PostgreSQL db 三个独立 Compose 服务组成。PostgreSQL 使用 named volume；普通 restart、容器重建和普通 `docker compose down` 设计为保留数据，只有显式 `down --volumes` 删除数据。

2026-09-19 已真实构建并启动 frontend/backend/db，迁移到 `20260912_0002`，三服务健康。五账号 API 隔离、草稿/版本、运行控制、范围导出、restart/down-up、备份及两次隔离恢复通过。首次启动发现并修复模板资源未打包。浏览器历史/分析/下载可用，五视口无页面级溢出；完整业务矩阵尚未完成。

同时发现影响正确性和真实 LLM 接入的缺口：非法选项答案进入有效统计、推断全失败仍标记完成、长调用过租约被误暂停，以及同步模型边界、无调用追踪、后端无外部出网。详见 [现场与 LLM 准备度报告](./verification/2026-09-19-live-deployment-and-llm-readiness.md)。

## 当前能力边界

- 回答、情绪、推断和样例数据来自 Mock 实现，不是实时模型调用，也不代表真实受访者或正式研究结论。
- 用户由部署者在产品外管理；没有注册、忘记密码、应用内用户管理、项目共享、角色或跨用户管理员读取。
- 固定人口字段、运行前设计检查、配额、试跑提升、研究批注和跨轮对比仍属于 P1/P2。
- 运行器位于 FastAPI 进程内，没有 Redis/Celery；数据库租约和检查点提供 P0 恢复语义，不提供生产级分布式任务 SLA。
- Quick Tunnel 是临时、可选、无固定地址/正式 SLA 的开发演示入口。
- 没有 `DATABASE_URL` 时，后端可以为纯业务测试装配内存 test double，但完整应用认证与持久化工作流不可用；这不是当前部署架构。
