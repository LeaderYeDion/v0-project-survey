# 可配置的模拟提前终止设计

## 目标

暂时屏蔽问卷与调研模拟中的提前终止，使默认启动方式下每位受访者回答全部问题。同时保留现有终止能力，并允许部署者在启动时通过一个布尔参数恢复两类终止规则。

## 配置契约

新增环境变量：

```bash
SIMULATION_TERMINATION_ENABLED=false
```

- `false`：默认值；受访者主动终止和调研方终止均不触发。
- `true`：恢复当前两类随机终止规则。
- 其他值：启动配置无效；部署脚本应在启动应用前拒绝配置，后端直接启动也应明确报错。

参数名称和值区分大小写，只接受字面值 `true` 和 `false`。

## 实现边界

### 后端配置

后端在创建默认 `MockEngine` 时读取并严格解析
`SIMULATION_TERMINATION_ENABLED`。`MockEngine` 接收一个布尔构造参数，
默认值为 `False`，因此测试、脚本或其他调用方未显式配置时同样关闭终止。

### 模拟引擎

当配置关闭时：

- `respondent_should_terminate` 固定返回 `False`；
- `interviewer_should_terminate` 固定返回 `False`；
- 回答质量检测、回答生成及题目遍历保持不变。

当配置开启时，两种判定继续执行现有概率与对话条件，不调整原有算法。

### 部署链路

在下列位置加入同一参数：

- `deploy/config/deploy.env.example`：展示默认值 `false`；
- `deploy/scripts/init-config.sh`：生成私有配置时写入默认值；
- `deploy/scripts/common.sh`：将参数列为必填项并严格校验；
- `deploy/README.md`：说明默认行为和切换方法；
- `deploy/RUNBOOK.md`：在配置示例及操作步骤中记录修改后须重启。

部署脚本加载 `deploy.env` 时会导出变量，FastAPI 子进程继承该值，无需增加
命令行参数或修改 API。

## 保持不变的行为

- 运行级取消能力继续可用。
- API 数据结构、终止状态、终止原因和前端展示保持不变。
- 已存在的历史终止数据仍可读取和展示。
- 问卷与调研共享同一个配置，不提供分别控制的参数。

## 测试

测试按以下行为编写：

1. `MockEngine` 默认关闭两类终止，即使对话满足原有条件也不终止。
2. 显式开启后仍执行既有随机终止逻辑。
3. 后端配置解析接受 `true`、`false` 和缺省值，拒绝其他值。
4. 部署契约覆盖示例配置、初始化配置、必填校验和布尔值校验。
5. 运行服务在关闭终止时，问卷和调研的所有会话均完成全部题目。
