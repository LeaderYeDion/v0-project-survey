## 2. 全局兼容约束

1. **Mock 必须保留且默认可用。** 未配置 LLM Key/endpoint/GPU 时，按原启动方式仍能使用登录、中英文、问卷、访谈、配置、结果和历史；不能让启动/登录全局依赖外部模型。
2. **显式选择 HTTP 路径。** 首版允许部署级配置切换，无需新增模型管理 UI。显式选择 HTTP 后配置缺失或调用失败应报错，不静默回退 Mock；切回 Mock 无需清库。
3. **业务模式与执行来源分开。** `survey/interview` 保持现意；轮次另保存 Mock、测试端点或实际模型来源及 model 等最小非敏感信息。测试端点不得显示为真实云端/本地 LLM。
4. **对已有契约做兼容扩展。** 保留固定角色字段、text/choice/scale（choice 为单选）、资源 ID/所有权、历史冻结配置和既有 API 语义；新增来源字段有兼容默认/缺省处理。新增持久字段时用迁移，不要求删库重建。
5. **旧数据仍可读。** 旧轮次缺少来源字段时明确显示“旧版/来源未记录”，或仅在有依据时标为 Mock；不能凭当前服务配置把旧轮次改标成真实模型。保存/查看旧数据不强制重新生成。
6. **Mock 辅助功能不全局删除。** 原 Mock 情绪/画像/态度推断保留演示用途并标识模拟；HTTP 路径未接入这些能力时禁用或显示未启用，不混入规则推断冒充模型分析。HTTP 回答的基础人数/进度、题目统计可复用。
7. **不扩大工程范围。** 无需引入 Agent 框架、队列系统、动态追问、流式 UI、自定义画像/多选、计费平台；凭据仅在服务端，不进入浏览器、日志明文或历史快照。

- [x] 工作项：补齐草稿保存与开始运行衔接、冻结请求需要的研究背景、提示词构建和访谈上下文传递。

- [x] 验收：合法回答进入展示；非法 JSON/类型、选项外字符串、越界量表/错误题目关联不得作为有效成功回答保存。HTTP 失败/超时显示失败，不显示完成、不永久等待。

- [x] 验收：HTTP 调用不阻塞健康/轮询请求；失败后已有成功回答仍可读，端点恢复后用户可新开一轮。无需本轮实现失败任务自动重试。
- [x] 验收：Mock 正常问卷/访谈通过相同兼容检查；如基础校验暴露 Mock 自定义题 ID 碰撞，仅修复使主线返回合法值所需的部分，不扩展成完整样例治理。

- 重跑台账 M0–M6 的小样本主线脚本，保存真实来源轮次并刷新/重新登录回看；检查实际调用耗时下的状态与超时。
